# retro-web

Vanilla HTML/CSS/JS frontend for the Retrospective Lab.

## Setup

Start the API first (`retro-api`), then:

```bash
npm start
```

Open http://localhost:8080

## Pages

| Page | Purpose |
|---|---|
| index.html | Dashboard |
| retrospectives.html | List & create |
| feedback.html | Submit feedback |
| board.html | Three-column board |
| analysis.html | Baseline analysis & approve suggestions |
| actions.html | Track actions |
| report.html | View/generate report |
